## What it is

Install job hub: jobs, site plans, proposals (with PO numbers, labor calculator, cost import and rate card), change orders folded into Proposals, crews and crew days, daily logs with photos, RFIs, expenses, job costing and a vendor-invoice tracker. The old "Sales app" (job costing + install scheduling) was folded in.
